# Private sample checklist

Request redacted COPIES of representative documents only after the contact and request are approved. This file sends nothing.

Ask for the correct routing identifier for each file; scanner model and output settings; expected duplicate behavior; representative normal, rotated, blank, unreadable and conflicting-code cases; and whether paperwork is one document per file.

Exclude unrelated customer/patient/employee data. Use the buyer's approved private transfer path and retention rules. Keep source copies unchanged and record SHA-256 hashes.

Do not invent Danpack identifiers or use another customer's samples to declare a new customer's workflow accepted.
