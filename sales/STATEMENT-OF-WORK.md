# Statement of work draft

This template requires a named buyer, confirmed site, accepted workflow definition and review before signing.

Implementation price: $10,000. Proposed milestone schedule: $5,000 upon approved agreement; $5,000 upon documented acceptance and handoff. This template does not create an invoice or charge.

Included work: one Windows/on-prem installation at one physical site, one document workflow, agreed barcode rules and duplicate policy, scanner-folder intake, PDF output, rejected-document review, operator/admin setup, customer-sample acceptance, verified backups and documented recovery.

Acceptance: all agreed sample expectations pass through the real processor; tested originals remain unchanged; the buyer verifies correct record association and retrieval; backup extraction and database integrity pass; the buyer receives installation, operating, security and recovery documentation.

Ownership: buyer controls installed infrastructure and their business data. The software is licensed, not sold, under LICENSE-AGREEMENT.md: a perpetual, non-exclusive license for one site. No exclusive IP assignment is implied by this draft.

Support: 30-day stabilization of the agreed workflow after acceptance. Ongoing support and new features are quoted separately.

Exclusions: ERP attachment, OCR/handwriting, signature checks, mixed-document splitting, custom mobile capture, extra sites/workflows and unsupported scanners. Unresolved acceptance failures block completion.

Buyer/site/workflow/identifier pattern/scanner/operator/backup destination/support contact and signatures: complete from confirmed facts before external use.
